# Analise_Fraude
Este repositório reúne scripts e arquivos para explorar a análise de transações financeiras e a identificação de possíveis fraudes em cartões bancários. Desenvolvido para atender desde iniciantes, o projeto utiliza exclusivamente Python, SQL e PostgreSQL, com foco nos fundamentos da análise de dados.

##  Para a correta execução do projeto  siga os passos abaixo 

### 1 - Passo Download da base de dados do kaggle conforme especificado no arquivo: Tratamento_Dados.ipynb
### 2 - Passo Tratamento desses dados conforme os passos de 1 ate 7 do arquivo:  Tratamento_Dados.ipynb
### 3 - Exportação dos dados tratados para  CSV conforme passo 8 do arquivo Tratamento_Dados.ipynb  
**  Lembrando que o passo 8 só deve ser executado caso todos os 7 primeiros não geraram erro.
### 4 - Importação do .csv tratado para o banco de dados Postgres conforme arquivo: Importacao_Dados.sql
### 5 - Análise exploratória dos dados conforme arquivo: Analise_Exploratoria.sql
